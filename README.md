# Quick Bunny — Level 1

A small keyboard-controlled obstacle course built with JavaScript sprites. Guide the blue bunny from the lower-left corner to the orange food near the upper-right while avoiding moving obstacles.

## Controls

Use the arrow keys to move. Reaching the food displays a win message; touching an obstacle sends the bunny back to its starting position.

## Stack

- HTML5
- JavaScript with p5.js and p5.play sprite helpers
- CSS and supporting libraries in `CSS/` and `lib/`

## Run

Open `index.html` in a browser with the repository files intact. The game uses a 600 × 600 canvas and has no package-manager setup.
